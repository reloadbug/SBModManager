## 二、头像从哪来

登录状态本来就有一套判定（`nexusAuth.js`），但**只拿用户名、不拿头像**。
本轮在**两套判定脚本**里各加了一段提取：

```js
const avatarEl = document.querySelector('img[class*="avatar"], a[href*="/users/"] img, img[src*="/avatars/"]');
const userLink = document.querySelector('a[href^="/users/"]:not([href*="myaccount"]):not([href*="sign_in"])');
const avatarUrl = avatarEl ? (avatarEl.currentSrc || avatarEl.src || null) : null;
```

- 头像取 `currentSrc || src`（`currentSrc` 才是 srcset 生效后的真实地址）；
- 用户名两路：**链接文字**（≤ 40 字才算，否则多半抓到了整块导航）
  → 兜底从 `href` 的 `/users/<name>` 里取并解码（纯头像链接没有文字）。

## 三、两个容易踩的坑

### 1. 头像**只在有值时覆盖缓存**

登录判定有两条路径，其中「首页看到 `Welcome back, X`」那条**拿不到头像**。
如果无条件写缓存：

```
先登录（拿到头像）→ 下次刷新走 Welcome back 分支 → 头像被写成 null → 顶栏退化成首字母
```

所以写缓存时：

```js
const patch = { loggedIn: true, user: inWin.user || null };
if (inWin.avatar) patch.avatar = inWin.avatar;   // ← 有值才覆盖
```

配套：缓存默认值加 `avatar: null`；退出登录时清空头像。

### 2. 内联 `onerror` 里的值要经 `data-ini` 传

头像 URL 可能 404 / 被图床拒绝。失败时换成首字母方块：

```html
<img class="acct-av" src="…" data-ini="N" referrerpolicy="no-referrer"
     onerror="var s=document.createElement('span');s.className='acct-av ph';
              s.textContent=this.dataset.ini||'?';this.replaceWith(s)">
```

- 首字母**不能**直接写在 `onerror` 里（`onerror="…'N'…"` 会被 HTML 解析器截断），
  走 `data-ini` 最稳；
- `referrerpolicy="no-referrer"`：Nexus 图床对带 referer 的请求可能 403；
- 按钮 `max-width:200px` + 名字省略号 —— 用户名很长也不会把顶栏撑爆。

## 五、连带修：`rmrf` 的「删完才抛」

跑全量时 `test:deps` 偶发红一条。查下来是**两个独立成因**：

1. **生产代码**：Windows 上 `fs.rmSync` 递归删目录会**先删干净再抛**
   （顶层 rmdir 与子项删除的竞态）。原 `rmrf` 只 `catch` 就走改名/报错分支，
   于是「删成功却报失败」—— 调用方以为目录还在，`sweepTrash()` 也收不到名字。
   修：`catch` 里先 `if (!fs.existsSync(dir)) return true;`。
2. **测试卫生**：`data/tmp` 里的 `.trash-*` 是**跨轮次**状态。
   `sweepStaleTmp()` 删不掉时会**改名**，而 Windows `renameSync` **保留目录 mtime**
   → 刚改名的垃圾桶带着「2 小时前」的 mtime，被同一次 `sweepTrash(10min)` 收走，
   混进断言结果。修：测试开跑前/收尾时清掉**自己造的名字**（不碰真实运行留下的）。

## 七、你要做什么

**重启应用**（新代码要重启才生效），然后看右上角：

1. 已登录 → 应该看到**圆形头像 + 你的 Nexus 用户名**；
2. 头像加载不出来 → 会自动变成**首字母方块**（这是设计好的兜底，不是 bug）；
3. 点它仍然进「设置 → 账号」区域，可以退出登录。

> 顺带一提：如果你的头像一直显示首字母方块，多半是图床对该图片做了防盗链，
> 不影响其它功能。
