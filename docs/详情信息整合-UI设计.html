Mod 详情信息整合 · UI 设计图 v2（单一界面）

最终软件里只有一个详情抽屉，不按状态分三套界面。顶部三个按钮只是设计评审用的预览开关，用来切换「同一套布局里的三份不同数据」，实际软件里不存在。所有字段固定顺序、固定行数；当前状态用不上的字段不是消失，而是灰色斜体占位（按你的要求「都保留、空着或灰色」）。

统一字段集（20 项，固定顺序）：①Mod ID ②状态 ③类型（含「服装 / CNS 服装」细分与判定依据）④版本 ⑤作者 ⑥分类 ⑦成人 ⑧下载量 ⑨点赞数 ⑩发布时间 ⑪更新时间 ⑫修改时间 ⑬开启时间 ⑭禁用时间 ⑮安装时间 ⑯登记状态 ⑰安装位置 ⑱压缩包位置 ⑲文件数 ⑳占用。
CNS 服装判定不再只看名称：名字含 cns、详细描述里提到、解压后文件名含 dekcns / cns 三者任一命中即算 CNS 服装；前置框架（UE4SS / CNS 本体 / ATOOL）仍单列为「前置组件」，不混进服装。
缓存：描述、机器翻译后的中文译文、版本/作者/下载量等，都写进本地 mod-info 档案，翻译成功一次后永久保留，不再重翻。
