自定义纳米战衣系统（CNS）是一个面向 Mod 作者的服装框架，允许在游戏内通过按 N 键呼出菜单，实时切换任意已安装的服装 Mod。它是绝大多数《剑星》服装类 Mod 的前置依赖。

安装要求：需要先安装 UE4SS。
注意：本 Mod 会写入 SB\Binaries 与 SB\Content，安装时管理器会自动备份被覆盖的原版文件。
