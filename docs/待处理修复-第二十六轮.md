## ① 需要覆盖的安装：给「对比」按钮

覆盖安装前，冲突行原来只有「定位」和「仍然覆盖」两个按钮 —— 用户看不到**要覆盖掉的那个 Mod 长什么样**。
现在每行多一个 **⇄ 对比**，弹出**左右并列**的对比框：

```
┌─ 覆盖对比：已装的 vs 要装的 ───────────────────────────────┐
│  ┌─ 已装的 ─────────┐      ┌─ 要装的 ─────────┐        │
│  │   [封面图]        │  vs  │   [封面图]        │        │
│  │ A2 Midriff v1.0   │      │ A2 Midriff v2.3   │        │
│  │ 作者 xNumber7x    │      │ 作者 xNumber7x    │        │
│  └───────────────────┘      └───────────────────┘        │
│  冲突文件：…/pak/xxx.pak（同大小 → 内容相同）              │
│                            [取消]  [仍然覆盖]             │
└──────────────────────────────────────────────────────────┘
```

- **图片是重点**：两侧都出封面（本地缓存优先，取不到退化成色块首字母，不留破图）；
- 一行里塞两个真按钮 → 行元素从 `<button>` 改成 `<div>`（按钮不能嵌按钮）；
- 「⇄ 对比」的点击必须**排在** `data-reveal-path` 之前，否则点对比只会弹资源管理器；
- 有多个登记者时，对比框默认比**第一个非自己的** Mod（对比框是「新 vs 旧」，一次比一个，
  其余的在框里列出来）；磁盘扫描到、没有登记者的文件**不给**对比按钮（没东西可比）。

## ② 详情抽屉：点空白即关

`#drawerMask` 遮罩与抽屉**同步开关**：点抽屉外的任何空白处关闭，`Esc` 也能关。
遮罩跟着抽屉一起开关（之前遮罩状态是各管各的，会出现「抽屉关了遮罩还在」）。

## ③ 点「下载」不再弹浏览器

原来点「⬇ 下载」会 `shell.openExternal` 拉一个浏览器窗口，用户还得在浏览器里再点一次。
现在**直接入队**：点完任务就进「下载管理」开始跑，切页、关抽屉都不中断。

> `shell.openExternal` 只保留在真正该开浏览器的地方（打开 Nexus 网页、登录页、GitHub Releases）。

## ④ 「无法识别这个压缩包的结构」—— 那 4 个包能装了

截图里报错的 4 个包，根因是**旧版 `pickDirs` 的判定 bug**：只认「根级 pak」这一种形态，
于是下面这些全部被打死：

| 包形态 | 现在怎么处理 |
|---|---|
| 裸 pak（根级就是 `.pak`/`.ucas`/`.utoc`） | 直接进 `~Mods` |
| **CNS 服装数据**（`.dekcns` / `.dekani`，常与 pak 混装） | 原样放进 `~Mods`，不是「不认识的文件」 |
| `~Mods` 直投包（包里自带 `~Mods\` 目录） | 按 `~Mods` 落盘 |
| `SB\` 原样落盘包（含 `SB\` 目录，按游戏根目录结构） | 按游戏根目录原样落盘 |

另外做了一件事：**已被旧 bug 判过「无法识别」的任务，重新分析一遍**，
能认的直接救回来（不用用户重新下载）。

## ⑤ 中断后「全部恢复」—— 接着下，不重头来

下载引擎现在支持**断点续传**：

- `destPath` 已有半截文件 → 带 `Range: bytes=<已下字节>-` 重新请求；
- 服务器回 **206** → 以追加方式写，进度**从已有字节起算**（界面上不会又从 0% 爬）；
- 服务器回 **200**（不支持 Range）→ **丢掉旧字节从头写**。
  ⚠️ 这步不能省：把 200 的完整响应追加在旧字节后面，会得到「前半截 + 完整一份」的坏包，
  比从零下还糟，而且要等解压时才暴露；
- 服务器回 **416**（Range 越界）→ 本地那份多半其实已经下完，把它挪成 `.stale-<时间戳>` 再重试。

> **失败时不再删半截文件** —— 那是下次续传的本钱。
> 只有用户**主动取消**才清掉（那时是真要丢弃）。

## ⑥ 多语言：14 种界面语言

简体中文是**原文语言**，另外 13 种带完整语言包，跟随系统语言自动选，也能在设置里手动切：

| 语言 | 代码 | 语言 | 代码 |
|---|---|---|---|
| 简体中文（原文） | `zh-CN` | 意大利语 | `it-IT` |
| 繁體中文 | `zh-TW` | 波兰语 | `pl-PL` |
| English | `en-US` | 土耳其语 | `tr-TR` |
| 日本語 | `ja-JP` | ไทย | `th-TH` |
| 한국어 | `ko-KR` | Deutsch | `de-DE` |
| Русский | `ru-RU` | Français | `fr-FR` |
| Español | `es-ES` | Português (Brasil) | `pt-BR` |

**做法**（对业务代码零侵入）：**中文原文即 key**，渲染完成后由 `i18n.js` 遍历 DOM 查表替换，
并用 `originals` Map 记住原文，保证切换语言幂等、可以来回横跳。
查表三段落兜底：① 整串命中 → ② 从两头剥噪声后整串命中 → ③ 片段替换。

> 为什么不用 `fetch` 读 JSON：界面 CSP 是 `script-src 'self'`，`file://` 下读不了本地 JSON，
> 所以语言包以 `<script>` 形式引入（`i18n.js` → 13 个语言包 → `app.js`，顺序不能乱）。

各语言包 **868 条**词条，与 `_probe/i18n-keys.json`（唯一真源）逐条一一对应。

## 测试

| 套件 | 结果 |
|---|---|
| `npm run test:i18n` | **135 断言 / 0 失败**（含数字模板 15 条） |
| `npm run test:drawer-mask` | 45 断言 / 0 失败 |
| `npm run test:resume` | 32 断言 / 0 失败 |
| `npm run test:pickdirs` | 71 断言 / 0 失败 |
| `npm run test:conflicts` | 覆盖对比相关断言 |
| `npm run test:all` | **29 个套件 / 1233 断言 / 0 失败**（退出码 0） |

本轮顺手修掉一个**测试自身的缺陷**：`file-download` / `batch-download` / `browse-onlynew` /
`desc-default` 四个套件靠 `indexOf('\n}\n')` 从 `app.js` 抽函数真身，
而工作区的 `app.js` 是 **CRLF** 行尾 —— 这个模式永远匹配不上，源码一旦是 CRLF 就整段挂掉。
现在读取时统一归一 `\r\n` → `\n`，测试不再依赖工作区行尾。

i18n 还做了**真实界面残留扫描**：`A 0 · B 0 · C1 0 · C2 3`，
剩下 3 条是运行时数据（Mod 名、Nexus 原文摘要），本就不该翻。

## 你要做什么

1. **重启应用**（新代码要重启才生效）；
2. 设置页把界面语言换成 English / 日本語 等，看界面是否整体跟着变；
3. 找一个会覆盖的 Mod 再装一次 —— 冲突行会多出 **⇄ 对比**，点开看左右两张封面图；
4. 下载中途按「取消」或直接关掉程序，重开后点「**全部恢复**」——
   进度应该从断点继续，而不是从 0% 重来。
