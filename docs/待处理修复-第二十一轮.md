# 「这种结构的 mod」到底该怎么装 —— 变体包排查（第二十一轮）

> 用户反馈：「这种结构的 mod，提示结构无法识别，你确认一下应该怎么处理，
> **找到 mod 的安装说明看看，压缩包里面有**」
> 截的是 mod 1430「BP Cooling suit (CNS compatible)」的压缩包内容。
>
> **⚠️ 新代码要重启应用才生效。**

---

## 一、先把包里的说明读出来（这步最该做）

压缩包里有 `Normal version Installation instructions.txt`（188 字节），全文：

```
Unzip the file and select the suit version and drag and drop the folder to
...\Steam\steamapps\common\StellarBlade\SB\Content\Paks\~mods.

If the "~mods" folder doesn't exist, create it.
```

两个关键信息：

1. **`select the suit version`（单数）→ 只能选一套。**
   A~G 七个目录里的 pak 全是 `ID223699-*`，本来就是**同一个游戏资产**，
   装两套只会互相覆盖。这条说明比任何启发式规则都可靠。
2. 作者说「把文件夹拖进 `~Mods`」。

## 二、结论：拍平到 `~Mods` 根级 + 只装一套（都对）

作者说的「拖文件夹」只是让手动安装的人少点几下（不用打开文件夹挑三个文件）。
**pak 的内部挂载点由 pak 自身决定，跟文件放在哪个目录无关**，所以拍平是等效的，
而且更稳 —— `~Mods` 根级有 407 个文件，游戏肯定读。

社区引用最广的 Fextralife 指南也是这么写的：

> Drop the `.pak` (and `.utoc`/`.ucas` if included) **into `~mods`**.
> **Avoid installing two mods that replace the same asset**, as they will conflict.

→ 我们的实现（拍平 + 同资产只能装一套）两条都对上了。

## 三、真正的 bug：明明识别成功了，却说「结构无法识别」

查队列里 1430 存的分析结果：

```
plan.options  = 7            ← 识别其实是**成功**的
plan.reason   = undefined    ← 但没写
→ 程序兜底成「结构无法自动识别，需要手动指定安装位置」
→ 卡片照实显示 → 你看到「结构无法识别」，以为是坏包
```

**这是文案 bug，不是识别失败。** 已修：

- `analyze` 现在**只要有候选就一定给 `reason`**：
  「包里有 7 套内容，需要你选要装哪些（互不相关的可以一起装）」
- `warnings` 里那句「压缩包结构与已知的 mod 布局都不匹配」也按情况分了岔
- 加了契约测试：**给了候选就不许出现「结构无法」字样**

## 四、顺带补上：**每套配色的预览图**

你说得对，包里有 7 张 jpg（`Cooling Suit_A.jpg` … `_G.jpg`），
**文件名和目录名一一对应** —— 那才是真正的「安装说明」。
不看图谁知道 A 是什么颜色？以前只能瞎点一个。

现在选择框里每套都显示缩略图：

| Mod | 候选 | 显示预览图 |
|---|---|---|
| 1430 BP Cooling suit | 7 | **7/7** |
| 437 BP Planet Diving Suit | 9 | **9/9** |
| 692 Eve BP Nude | 7 | **7/7** |
| 1544 Valby | 2 | **2/2** |
| 1378 / 2595 / 1981 | 2 | 0（包里本来就没图，不显示图位） |

实现要点：

- 匹配规则：目录内的图 → **与目录名同名的图** → 前缀兜底；
  名字比较前先归一（大小写 / `_` / `-` / 空格等价），
  于是 `Cooling suit_A` 能配上 `Cooling Suit_A.jpg`
- **只解那几张图**，不全解 —— 这个包 47MB、全解 142MB，只为 7 张 jpg 不值得
- 缓存 `data/cache/variants/`，第二次打开不再解压
- 包里没图就不显示图位（不留一排空框）

## 五、所以你现在会看到什么

重启应用后，1430 点「确认安装」：

1. 弹出「选择要安装哪些内容」
2. **7 套配色各带一张缩略图**，标着 `第 1 组 · 只能选一套`
3. **已经默认选好 A 了** —— 想换颜色点另一张，再点「安装选中的（1）」
4. 选中的三个文件（`.pak` / `.ucas` / `.utoc`）拍平放进 `~Mods`
