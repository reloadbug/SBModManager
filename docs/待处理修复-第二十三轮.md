# 浏览页吸顶 + 「不喜欢」黑名单（第二十三轮）

> 用户诉求：
> 「浏览 mod 的时候，顶部筛选和多选按钮一直显示到顶部，不会随滚动而消失；
> mod 支持不喜欢按钮，点击后被加入到黑名单，立刻加入，
> 顶部筛选对应增加黑名单的过滤功能，默认不显示黑名单 mod。」
>
> **⚠️ 新代码要重启应用才生效。**

---

## 一、顶部栏吸顶

浏览页的**排序 / 显示范围 / 筛选 / 统计行**现在固定在顶部，往下翻多少都不会消失 ——
想换排序或筛选不用滚回最上面。

实测（滚到 1015px 处）：

```
滚动前  bodyTop=54   headTop=54
滚动后  bodyTop=54   headTop=54   sticky=true    ← 一直贴着顶部
```

> 🔧 实现上踩了一个坑：`position:sticky` 的 `top` 约束的是 **margin box**，
> 而 `margin-top:-16px`（用来抵消滚动容器的 padding）会把 border box 又推下去 16px。
> 只写 `top:0` 会停在**距顶 16px** 处，卡片从那条缝里滚过去。
> 必须写成 `top:-16px` 与 `margin:-16px` **配套**。

## 二、「🚫 不喜欢」→ 立刻拉黑

每张卡片底部多了一个 **🚫 不喜欢** 按钮。点一下：

1. 这张卡片**立刻**从列表消失（不用等落盘）；
2. 记进本地黑名单 `data/blacklist.json`；
3. 顶部统计行注明「已隐藏黑名单（共 N 个）」。

实测：

```
id=1496  卡片数 24 → 23  gone=true  persisted=true
统计行「共 3,074 个 Mod · 已加载 23 个 · 已隐藏黑名单（共 1 个）」
提示「已加入黑名单，不再显示」
```

**黑名单只存在本地**（按 Nexus modId 认），不上传、不同步到 Nexus 账号。
想彻底清空就删掉 `data/blacklist.json`。

## 三、顶部黑名单筛选（默认隐藏）

顶部新增一组三态：

| 选项 | 效果 |
|---|---|
| **隐藏黑名单**（默认） | 拉黑过的 mod 不出现 |
| 显示全部 | 黑名单也一起显示（临时看看） |
| **只看黑名单** | 只列黑名单里的 mod |

实测「只看黑名单」：

```
卡片 = [1496]   统计行「共 1 个 Mod · 已加载 1 个 · 只看黑名单」
卡片上的按钮变成「♻ 移出黑名单」
```

> 🔧 **「只看黑名单」不走翻页**：黑名单通常只有几条，而 Nexus 有 3000+ 个 mod，
> 靠「翻页 + 过滤」要翻遍全站才凑得出来（一次 24 个，翻 20 页也才 480 个）——
> 点一下等半分钟还看不到东西。所以它**直接读本地记录**渲染卡片
> （`add()` 时把名字/作者/封面一起存下来了），**零网络请求，秒开**。

## 四、行为细节

| 场景 | 结果 |
|---|---|
| 「隐藏黑名单」里点不喜欢 | 卡片摘掉，并从这个列表的数据里剔除（统计行才对得上） |
| 「显示全部」里点不喜欢 | 卡片摘掉，但数据保留（切回来还能看到） |
| 「只看黑名单」里点按钮 | 按钮是「♻ 移出黑名单」，点了就恢复显示 |
| 写盘失败 | 只提示，**不回滚**（把卡片闪回来只会更困惑） |

## 七、你要做什么

**重启应用**（新代码要重启才生效），然后：

1. 进「浏览 Mod」页，往下滚 —— 顶部那一整条（排序 / 范围 / 筛选 / 统计）不会消失；
2. 在任意卡片上点 **🚫 不喜欢** —— 卡片立刻消失，顶部统计行会注明「已隐藏黑名单（共 1 个）」；
3. 顶部切到 **只看黑名单** —— 能看到刚拉黑的那些，点 **♻ 移出黑名单** 恢复。
